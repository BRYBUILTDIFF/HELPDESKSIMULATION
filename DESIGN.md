# User workspace

The approved direction is clear wayfinding: a quiet green navigation rail, a readable troubleshooting workspace, and a separate entry into practice. The primary mode is Operate.

Use flat warm-white surfaces in light mode and deep green-black surfaces in dark mode. The navigation rail remains deep green in both. Use the existing DM Sans face for interface text; reserve monospace for commands and code. Green identifies actions and selection; red is reserved for destructive actions and errors.

The first screen leads with “Describe your IT problem.” and a generous text input. Common issues are rows rather than a wall of cards. History stays compact and readable. Do not add gradients, decorative glow, technical-looking labels, promotional claims, or invented metrics.

Maintain current chat, history, simulation, lab, and account behavior. Settings remain centered as requested. Preserve mobile sidebar collapse and light/dark preferences. Keyboard focus must remain visible; reduced motion disables decorative transitions.

Scope: user workspace, public authentication, password setup, and administrator screens. Admin uses the same green rail and semantic colors, with denser tables and forms. Keep destructive actions red and administrative status colors meaningful. Future simulation-specific redesigns should preserve the real terminal and remote desktop affordances.
